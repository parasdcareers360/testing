1. TWO POINTERS
================================================================================
WHAT IT IS: Use two indices moving through a structure (often sorted array/string)
to avoid nested loops.
WHEN TO USE:
  - Sorted array, pair-sum, or "find two/three elements that satisfy X"
  - Palindrome checks, merging two sorted arrays
  - Removing duplicates in place
TEMPLATE:
  left = 0, right = n-1
  while left < right:
      if condition_met: return / record
      elif need_bigger_sum: left += 1
      else: right -= 1
TIME: O(n)
EXAMPLES:
  - Two Sum II (sorted array)
  - 3Sum / 4Sum
  - Container With Most Water
  - Valid Palindrome
  - Sort Colors (Dutch National Flag)
  - Trapping Rain Water (two-pointer variant)

2. SLIDING WINDOW
================================================================================
WHAT IT IS: Maintain a window [left, right] over an array/string and expand/shrink
it based on a condition instead of recomputing from scratch.
WHEN TO USE:
  - "Contiguous subarray/substring" + constraint (max/min length, sum, distinct chars)
  - Fixed-size window (size k) or variable-size window
TEMPLATE (variable window):
  left = 0
  for right in range(n):
      add arr[right] to window
      while window_invalid:
          remove arr[left]; left += 1
      update answer with window [left, right]
TIME: O(n)
EXAMPLES:
  - Longest Substring Without Repeating Characters
  - Minimum Window Substring
  - Longest Repeating Character Replacement
  - Sliding Window Maximum (uses monotonic deque)
  - Maximum Sum Subarray of Size K
  - Fruit Into Baskets
  - Permutation in String

3. FAST & SLOW POINTERS (Floyd's Cycle Detection)
================================================================================
WHAT IT IS: Two pointers moving at different speeds through a linked list/sequence.
WHEN TO USE:
  - Cycle detection in linked lists
  - Finding middle of linked list
  - Detecting cycles in a "functional graph" (e.g., array as next-pointers)
TEMPLATE:
  slow = head; fast = head
  while fast and fast.next:
      slow = slow.next
      fast = fast.next.next
      if slow == fast: cycle found
TIME: O(n)
EXAMPLES:
  - Linked List Cycle I / II
  - Happy Number
  - Middle of the Linked List
  - Palindrome Linked List
  - Find the Duplicate Number

4. MERGE INTERVALS
================================================================================
WHAT IT IS: Sort intervals by start time, then merge/compare overlapping ranges.
WHEN TO USE:
  - Problems mentioning "intervals", "meetings", "schedules", "ranges"
TEMPLATE:
  sort intervals by start
  result = [intervals[0]]
  for interval in intervals[1:]:
      if interval.start <= result[-1].end:
          merge (extend end)
      else:
          append interval
TIME: O(n log n)
EXAMPLES:
  - Merge Intervals
  - Insert Interval
  - Non-overlapping Intervals
  - Meeting Rooms I / II
  - Employee Free Time

5. CYCLIC SORT
================================================================================
WHAT IT IS: For arrays with numbers in range [1..n], place each number at its
correct index in O(n) using swaps.
WHEN TO USE:
  - "Find missing/duplicate number(s)" in range [1..n] with O(n) time, O(1) space
TEMPLATE:
  i = 0
  while i < n:
      correct = arr[i] - 1
      if arr[i] != arr[correct]: swap(arr[i], arr[correct])
      else: i += 1
TIME: O(n)
EXAMPLES:
  - Find the Duplicate Number
  - Find All Missing Numbers
  - Find All Duplicates in an Array
  - First Missing Positive
  - Set Mismatch

6. IN-PLACE LINKED LIST REVERSAL
================================================================================
WHAT IT IS: Reverse (parts of) a linked list by rewiring next pointers without
extra space.
WHEN TO USE: "Reverse a linked list", "reverse in groups of k", "reverse sublist"
TEMPLATE:
  prev = None; curr = head
  while curr:
      next_temp = curr.next
      curr.next = prev
      prev = curr
      curr = next_temp
TIME: O(n)
EXAMPLES:
  - Reverse Linked List
  - Reverse Linked List II (sublist)
  - Reverse Nodes in k-Group
  - Swap Nodes in Pairs
  - Rotate List

7. TREE BFS (Level Order Traversal)
================================================================================
WHAT IT IS: Traverse tree/graph level by level using a queue.
WHEN TO USE: "Level order", "minimum depth", "connect nodes at same level",
"shortest path in unweighted graph"
TEMPLATE:
  queue = [root]
  while queue:
      level_size = len(queue)
      for _ in range(level_size):
          node = queue.pop(0)
          process(node)
          queue.extend(node.children)
TIME: O(n)
EXAMPLES:
  - Binary Tree Level Order Traversal
  - Zigzag Level Order Traversal
  - Minimum Depth of Binary Tree
  - Populating Next Right Pointers
  - Word Ladder (BFS on graph)
  - Rotting Oranges

8. TREE DFS (Preorder / Inorder / Postorder)
================================================================================
WHAT IT IS: Recursively (or with explicit stack) explore as deep as possible
before backtracking.
WHEN TO USE: "All root-to-leaf paths", "path sum", "tree height/diameter",
"validate/construct tree"
TEMPLATE (recursive):
  def dfs(node, path):
      if not node: return
      path.append(node.val)
      if is_leaf(node): process(path)
      dfs(node.left, path); dfs(node.right, path)
      path.pop()
TIME: O(n)
EXAMPLES:
  - Path Sum I / II / III
  - Binary Tree Maximum Path Sum
  - Diameter of Binary Tree
  - Validate Binary Search Tree
  - Lowest Common Ancestor
  - Serialize/Deserialize Binary Tree

10. SUBSETS / BACKTRACKING (Combinatorial Generation)
================================================================================
WHAT IT IS: Explore all combinations/permutations/subsets via recursive choice
-> explore -> un-choose (backtrack).
WHEN TO USE: "All subsets", "all permutations", "combination sum", "N-Queens",
"generate parentheses", constraint satisfaction
TEMPLATE:
  def backtrack(path, choices):
      if is_solution(path): record(path); return (or continue for all)
      for choice in choices:
          if valid(choice):
              path.append(choice)
              backtrack(path, remaining_choices)
              path.pop()   # undo
TIME: O(2^n) or O(n!) depending on problem
EXAMPLES:
  - Subsets I / II
  - Permutations I / II
  - Combination Sum I / II / III
  - N-Queens
  - Word Search
  - Generate Parentheses
  - Palindrome Partitioning
  - Sudoku Solver

11. MODIFIED BINARY SEARCH
================================================================================
WHAT IT IS: Binary search adapted for rotated arrays, answer spaces, or
"find boundary" problems.
WHEN TO USE: "Sorted/rotated array", "find first/last occurrence",
"minimize/maximize X such that condition holds" (binary search on answer)
TEMPLATE:
  lo, hi = 0, n-1
  while lo <= hi:
      mid = (lo + hi) // 2
      if condition(mid): hi = mid - 1  (or record & narrow)
      else: lo = mid + 1
TIME: O(log n)
EXAMPLES:
  - Binary Search
  - Search in Rotated Sorted Array
  - Find Minimum in Rotated Sorted Array
  - Search a 2D Matrix
  - Koko Eating Bananas (binary search on answer)
  - Capacity to Ship Packages Within D Days
  - Split Array Largest Sum
  - Median of Two Sorted Arrays

13. TOP K ELEMENTS (Heap)
================================================================================
WHAT IT IS: Maintain a heap of size k to track top/bottom k elements efficiently.
WHEN TO USE: "Top/K-th largest/smallest", "K closest points", "frequency sort"
TEMPLATE:
  heap = []
  for item in items:

EXAMPLES:

  - K Closest Points to Origin
  - Kth Largest Element in a Stream

14. K-WAY MERGE
================================================================================
WHAT IT IS: Merge k sorted lists/arrays using a min-heap of size k.
WHEN TO USE: "Merge k sorted lists", "smallest range covering k lists",
"k-th smallest in sorted matrix"
TEMPLATE:
  heap = [(list[i][0], i, 0) for i in range(k)]
  heapify(heap)
  while heap:
      val, list_idx, elem_idx = heappop(heap)
      process(val)
      if next element exists: heappush(heap, next)
TIME: O(N log k) where N = total elements
EXAMPLES:
  - Merge k Sorted Lists
  - Kth Smallest Element in a Sorted Matrix
  - Smallest Range Covering Elements from K Lists
  - Find K Pairs with Smallest Sums

16. BACKTRACKING ON GRAPHS / GRIDS (Matrix Traversal)
================================================================================
WHAT IT IS: DFS/BFS over grid cells, marking visited, exploring 4/8 directions.

17. TOPOLOGICAL SORT (Graph — DAG Ordering)
================================================================================
WHAT IT IS: Order nodes of a DAG so every edge u->v has u before v. Uses
Kahn's algorithm (BFS + in-degree) or DFS + stack.
WHEN TO USE: "Dependencies", "prerequisites", "build order", "course schedule"
TEMPLATE (Kahn's):
  compute in-degree for all nodes
  queue = nodes with in-degree 0
  while queue:
      node = queue.pop()
      result.append(node)
      for neighbor in graph[node]:
          in-degree[neighbor] -= 1
          if in-degree[neighbor] == 0: queue.append(neighbor)
TIME: O(V + E)
EXAMPLES:
  - Course Schedule I / II
  - Alien Dictionary
  - Sequence Reconstruction
  - Minimum Height Trees

18. UNION FIND (Disjoint Set Union - DSU)
================================================================================
WHAT IT IS: Track connectivity/components with union + find operations
(path compression + union by rank for near O(1) ops).
WHEN TO USE: "Connected components", "cycle detection in undirected graph",
"number of provinces/islands via merging", "Kruskal's MST"
TEMPLATE:
  parent = [i for i in range(n)]
  def find(x):
      if parent[x] != x: parent[x] = find(parent[x])
      return parent[x]
  def union(x, y):
      rx, ry = find(x), find(y)
      if rx != ry: parent[rx] = ry
TIME: O(log n) amortized ~O(1) per op with path compression
EXAMPLES:
  - Number of Provinces
  - Redundant Connection
  - Accounts Merge
  - Graph Valid Tree
  - Number of Islands II
  - Most Stones Removed with Same Row or Column

19. GRAPH SHORTEST PATH (Dijkstra / Bellman-Ford / Floyd-Warshall)
================================================================================
WHAT IT IS: Weighted shortest path algorithms.
WHEN TO USE:
  - Dijkstra: non-negative weights, single source
  - Bellman-Ford: negative weights allowed, detect negative cycles
  - Floyd-Warshall: all-pairs shortest path, small graph
TEMPLATE (Dijkstra):
  dist = {node: inf}; dist[src] = 0
  min_heap = [(0, src)]
  while heap:
      d, node = heappop(heap)
      if d > dist[node]: continue
      for nbr, w in graph[node]:
          if d + w < dist[nbr]:
              dist[nbr] = d + w; heappush(heap, (d+w, nbr))
TIME: Dijkstra O(E log V), Bellman-Ford O(V*E), Floyd-Warshall O(V^3)
EXAMPLES:
  - Network Delay Time
  - Cheapest Flights Within K Stops
  - Path With Minimum Effort
  - Swim in Rising Water

21. DYNAMIC PROGRAMMING — 1D
================================================================================
WHAT IT IS: Break problem into overlapping subproblems; store results in a
1D array (memoization or tabulation).
WHEN TO USE: "Count ways", "min/max cost", "can you reach", with recurrence
relying on smaller indices
TEMPLATE:
  dp[0] = base_case
  for i in range(1, n):
      dp[i] = f(dp[i-1], dp[i-2], ...)
TIME: O(n)
EXAMPLES:
  - Climbing Stairs
  - House Robber I / II
  - Coin Change
  - Longest Increasing Subsequence
  - Word Break
  - Decode Ways
  - Maximum Subarray (Kadane's)

22. DYNAMIC PROGRAMMING — 2D (Grid / Two Sequences)
================================================================================
WHAT IT IS: DP table dp[i][j] representing subproblem on two indices/sequences.
WHEN TO USE: "Two strings", "grid path", "edit distance", "LCS-type problems"
TEMPLATE:
  dp[0][*] / dp[*][0] = base cases
  for i in range(1, m):
      for j in range(1, n):
          dp[i][j] = f(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
TIME: O(m*n)
EXAMPLES:
  - Longest Common Subsequence
  - Edit Distance
  - Unique Paths I / II
  - Minimum Path Sum
  - Interleaving String
  - Regular Expression Matching
  - Distinct Subsequences

23. DYNAMIC PROGRAMMING — KNAPSACK (0/1, Unbounded, Subset Sum)
================================================================================
WHAT IT IS: Choose items with weight/value constraints to optimize a total.
WHEN TO USE: "Subset sum", "partition equal subset", "target sum", "coin change
(min coins / number of ways)"
TEMPLATE (0/1 knapsack):
  dp[w] = max value achievable with capacity w
  for item in items:
      for w in range(capacity, item.weight - 1, -1):
          dp[w] = max(dp[w], dp[w - item.weight] + item.value)
TIME: O(n * capacity)
EXAMPLES:
  - Partition Equal Subset Sum
  - Target Sum
  - Coin Change II (number of ways)
  - Last Stone Weight II
  - Ones and Zeroes

24. DYNAMIC PROGRAMMING — INTERVAL / RANGE
================================================================================
WHAT IT IS: dp[i][j] represents the answer for subarray/substring [i..j];
build up from smaller ranges to larger ranges.
WHEN TO USE: "Palindromic substrings", "matrix chain multiplication style",
"merge intervals to minimize/maximize cost"
TEMPLATE:
  for length in range(2, n+1):
      for i in range(0, n-length+1):
          j = i + length - 1
          dp[i][j] = f(dp[i][k], dp[k+1][j]) for k in range(i, j)
TIME: O(n^3) typically
EXAMPLES:
  - Longest Palindromic Substring/Subsequence
  - Burst Balloons
  - Minimum Cost to Merge Stones
  - Palindrome Partitioning II

25. DYNAMIC PROGRAMMING — TREE DP
================================================================================
WHAT IT IS: DP defined over tree nodes, combining children's DP states.
WHEN TO USE: "Max/min value in a tree with parent-child constraints"
TEMPLATE:
  def dfs(node):
      if not node: return base_case
      left = dfs(node.left); right = dfs(node.right)

TIME: O(n)
EXAMPLES:

  - Longest Path with Same Value in Tree

26. DYNAMIC PROGRAMMING — BITMASK
================================================================================
WHAT IT IS: Use a bitmask to represent subset states (visited nodes, assigned
items) as DP dimension. Feasible when n is small (<=20).
WHEN TO USE: "Traveling salesman", "assign tasks to people", "visit all nodes"
TEMPLATE:
  dp[mask][i] = best cost visiting subset `mask` ending at i

TIME: O(n^2 * 2^n)

28. MONOTONIC STACK
================================================================================
WHAT IT IS: Stack that maintains increasing/decreasing order; pop elements
that violate the order to find next greater/smaller element efficiently.
WHEN TO USE: "Next greater/smaller element", "largest rectangle in histogram",
"daily temperatures", "stock span"
TEMPLATE:
  stack = []
  for i, val in enumerate(arr):
      while stack and arr[stack[-1]] < val:
          idx = stack.pop(); result[idx] = i - idx  (or val)
      stack.append(i)
TIME: O(n)
EXAMPLES:
  - Daily Temperatures
  - Largest Rectangle in Histogram
  - Next Greater Element I / II
  - Trapping Rain Water (stack variant)
  - Remove K Digits
  - Online Stock Span

29. MONOTONIC DEQUE (Sliding Window Max/Min)
================================================================================
WHAT IT IS: Deque that keeps elements in monotonic order to get window max/min
in O(1) amortized.
WHEN TO USE: "Sliding window maximum/minimum"
TEMPLATE:
  deque = []
  for i, val in enumerate(arr):
      while deque and arr[deque[-1]] <= val: deque.pop()
      deque.append(i)
      if deque[0] <= i - k: deque.popleft()
      if i >= k-1: result.append(arr[deque[0]])
TIME: O(n)
EXAMPLES:
  - Sliding Window Maximum
  - Shortest Subarray with Sum at Least K
  - Constrained Subsequence Sum

30. PREFIX SUM / DIFFERENCE ARRAY
================================================================================
WHAT IT IS: Precompute cumulative sums to answer range-sum queries in O(1),
or use difference arrays for O(1) range updates.
WHEN TO USE: "Range sum queries", "subarray sum equals K", "range update then
query final array"
TEMPLATE:
  prefix[0] = 0
  for i in range(n): prefix[i+1] = prefix[i] + arr[i]
  range_sum(l, r) = prefix[r+1] - prefix[l]
TIME: O(n) preprocessing, O(1) per query
EXAMPLES:
  - Range Sum Query - Immutable
  - Subarray Sum Equals K
  - Contiguous Array
  - Product of Array Except Self
  - Range Addition (difference array)
  - Corporate Flight Bookings

31. FENWICK TREE / BINARY INDEXED TREE (BIT)
================================================================================
WHAT IT IS: Data structure for prefix sums with O(log n) point update and
range query.
WHEN TO USE: "Range sum query - mutable", "count of smaller numbers after self"
TEMPLATE:
  update(i, delta): while i <= n: tree[i] += delta; i += i & (-i)
  query(i): total = 0; while i > 0: total += tree[i]; i -= i & (-i); return total
TIME: O(log n) per update/query
EXAMPLES:
  - Range Sum Query - Mutable
  - Count of Smaller Numbers After Self
  - Count of Range Sum

randomized pivot selection.
WHEN TO USE: "Random pick from stream/list", "shuffle array"
TEMPLATE (reservoir sampling of 1): for i-th element (1-indexed), keep it with
probability 1/i
TIME: O(n)
EXAMPLES:
  - Linked List Random Node
  - Random Pick Index
  - Shuffle an Array
  - Random Pick with Weight

40. DESIGN / SIMULATION PATTERNS
================================================================================
WHAT IT IS: No single algorithmic trick — implement a data structure or
simulate a process exactly as described, choosing the right underlying
structures (hashmap + doubly linked list, multiple stacks/queues, etc.).
WHEN TO USE: "Design a...", "implement a...", "simulate the following process"
EXAMPLES:
  - LRU Cache (hashmap + doubly linked list)
  - LFU Cache
  - Design Twitter
  - Min Stack / Max Stack
  - Design Circular Queue/Buffer
  - Snake Game
  - Insert Delete GetRandom O(1)

41. MATH / NUMBER THEORY PATTERNS
================================================================================
WHAT IT IS: GCD/LCM, sieve of Eratosthenes, modular arithmetic, combinatorics.
WHEN TO USE: "Prime numbers", "GCD/LCM", "modulo large number", "count
combinations"
TEMPLATE (Sieve): mark multiples of each prime starting from 2 up to sqrt(n)
TIME: O(n log log n) for sieve
EXAMPLES:
  - Count Primes
  - Sieve of Eratosthenes based problems
  - Pow(x, n) — fast exponentiation
  - Excel Sheet Column Number/Title
  - Greatest Common Divisor of Strings
  - Unique Paths (combinatorics: C(m+n-2, m-1))

42. HASHMAP / HASHSET PATTERNS
================================================================================
WHAT IT IS: Use hashing for O(1) average lookup to avoid nested loops or track
frequency/seen state.
WHEN TO USE: "Two Sum", "group anagrams", "check duplicates", "frequency count"
TEMPLATE:
  seen = {}
  for i, val in enumerate(arr):
      if target - val in seen: return (seen[target-val], i)
      seen[val] = i
TIME: O(n)
EXAMPLES:
  - Two Sum
  - Group Anagrams
  - Longest Consecutive Sequence
  - Subarray Sum Equals K
  - Contains Duplicate II
  - Isomorphic Strings

================================================================================
43. MULTI-SOURCE BFS
================================================================================
WHAT IT IS: BFS starting simultaneously from multiple source nodes, useful for
"distance from nearest X" type problems.
WHEN TO USE: "Nearest 0", "rotting oranges", "walls and gates"
TEMPLATE:
  queue = all source nodes with distance 0
  standard BFS expansion, tracking distance/level
TIME: O(V + E)
EXAMPLES:
  - Rotting Oranges
  - 01 Matrix (Distance to nearest 0)
  - Walls and Gates
  - Shortest Distance from All Buildings

================================================================================
44. A* / HEURISTIC SEARCH (Advanced Graph)
================================================================================
WHAT IT IS: Dijkstra augmented with a heuristic function to prioritize
promising paths.
WHEN TO USE: Rare on LeetCode; appears in pathfinding puzzles with grid + weights
TIME: depends on heuristic quality
EXAMPLES:
  - Sliding Puzzle (BFS on state space, sometimes with heuristic)
  - Shortest Path in a Grid with Obstacle Elimination

NOTES
--------------------------------------------------------------------------------
- Many "hard" LeetCode problems are simply combinations of 2-3 patterns above
  (e.g., Sliding Window + HashMap, or DP + Bitmask, or Backtracking + Trie).
- When stuck, ask: "What is the brute force?" then look for which pattern
  removes the redundant work in that brute force (that's usually the pattern
  the problem wants).
- Always identify: input size constraints (n) to guess expected complexity:
    n <= ~20         -> exponential/bitmask DP/backtracking OK
    n <= ~1,000       -> O(n^2) OK
    n <= ~100,000     -> O(n log n) needed
    n <= ~1,000,000+  -> O(n) or O(n log n) with small constant
