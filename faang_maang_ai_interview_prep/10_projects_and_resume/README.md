# 10 — Projects & Resume

> **Type:** Study notes + templates (mixed — see each file)

Turns your real work (Django/DRF APIs, PostgreSQL, Elasticsearch, Docker, microservices, OCR/PDF
pipelines) into resume bullets, a GitHub presence, and spoken stories that survive a recruiter
screen, a resume-review bar raiser, and a "walk me through a project" deep-dive — without
inventing anything you didn't do.

| File | Purpose |
|---|---|
| [`faang_maang_resume_template.md`](faang_maang_resume_template.md) | General SWE/Backend resume structure and bullet formula |
| [`ai_backend_resume_template.md`](ai_backend_resume_template.md) | Variant resume aimed at AI Backend / ML Platform roles |
| [`linkedin_headline_and_about.md`](linkedin_headline_and_about.md) | Headline + About section templates |
| [`github_project_readme_template.md`](github_project_readme_template.md) | README structure so a reviewer understands your project in 60 seconds |
| [`project_architecture_explanation_template.md`](project_architecture_explanation_template.md) | Script for "walk me through the architecture" |
| [`star_format_project_stories.md`](star_format_project_stories.md) | Converting project work into STAR-format stories (project angle, not behavioral-only) |
| [`project_deep_dive_template.md`](project_deep_dive_template.md) | Prep sheet for a dedicated project deep-dive round |
| `sample_storytelling/*.md` | One worked example per stack piece (DRF, PostgreSQL, Elasticsearch, OCR, Docker, microservices, API gateway) showing what a *good* answer sounds like |

## How to use this folder

1. Fill `faang_maang_resume_template.md` (or the AI variant) first — it forces you to quantify
   your real work, which is the hard part.
2. Pick your 2-3 strongest projects and write one `sample_storytelling`-style page for each,
   using the closest matching example file as a model.
3. Before any onsite, re-read your own deep-dive prep sheets the morning of — not the week
   before.

See also [`11_behavioral_and_leadership/star_method_guide.md`](../11_behavioral_and_leadership/star_method_guide.md)
for the general STAR mechanics this folder assumes you already know.
