# 15 — Progress Tracking

> **Type:** Template hub — see each file

The single place to see "am I actually getting better" across the whole 12 weeks, separate from
[`13_job_application_tracking/`](../13_job_application_tracking/) which tracks the job search
itself.

| File | Purpose |
|---|---|
| [`overall_progress_dashboard.md`](overall_progress_dashboard.md) | One table, updated weekly, rolling up every other tracker in this workspace |
| [`skills_self_assessment.md`](skills_self_assessment.md) | Honest 1-5 self-rating per skill area, at the start and re-taken periodically |
| [`twelve_week_progress_log.md`](twelve_week_progress_log.md) | One row per week: plan vs. actual, for the whole 12-week arc |

## How this differs from `00_master_plan/weekly_review.md`

`weekly_review.md` is a *reflection* you write in prose each week. The three files here are pure
tables meant to be scanned in 30 seconds to answer "where do I stand right now" — fill in both,
they serve different moments (weekly reflection vs. any-time status check).
