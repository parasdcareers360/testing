# 13 — Job Application Tracking

> **Type:** Template hub — see each file

Separate from *prep* progress (that's [`15_progress_tracking/`](../15_progress_tracking/)) — this
folder tracks the job search itself: who you've applied to, where you are in each pipeline, and
whether your practice volume is keeping pace with your application volume.

| File | Purpose |
|---|---|
| [`company_application_tracker.md`](company_application_tracker.md) | Every application, stage, and next action, one row each |
| [`problem_solving_progress_tracker.md`](problem_solving_progress_tracker.md) | Weekly DSA problem-count rollup across all pattern trackers |
| [`weekly_scorecard.md`](weekly_scorecard.md) | One-line-per-week snapshot: applications sent, interviews had, offers |

## Why track applications separately from prep

Per [`../00_master_plan/README.md`](../00_master_plan/README.md), applications should start around
week 6-7, well before you feel "fully ready" — loops take 3-6 weeks end-to-end. This folder exists
so application volume is a visible number you're accountable to, not something that quietly slips
while you keep "just one more week" of studying.
