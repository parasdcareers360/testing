# Problem-Solving Progress Tracker

> **Type:** Template — copy or fill in directly

A weekly rollup pulled from each pattern's `problem_tracker.md` under
[`../02_dsa_and_coding/patterns/`](../02_dsa_and_coding/patterns/) — one row per week, so you can
see total volume and pattern coverage at a glance instead of digging through 16 separate files.

| Week | Problems solved this week | Cumulative total | Patterns touched | Weakest pattern this week |
|---|---|---|---|---|
| | | | | |

| 3 | 9 | 24 | Linked Lists, Binary Search | Linked Lists — fumbled fast/slow pointer edge case on odd-length lists |

## Target pace

~7-9 problems/week keeps you on pace to cover all 16 patterns with 8-12 problems each inside the
12-week plan (see [`../00_master_plan/12_week_plan.md`](../00_master_plan/12_week_plan.md)). If
cumulative total is falling behind `week × 8`, that's a signal to cut a non-DSA topic that week,
not to panic-grind — see `priority_topics.md` for what's safe to defer.
