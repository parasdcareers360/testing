# Story Bank Tracker

> **Type:** Template — copy or fill in directly

One row per real story. Map it against every question category it can answer — a good story
usually covers 3-4 categories depending on which part you emphasize when telling it.

| # | Story (short name) | Situation summary | Amazon LPs covered | Conflict | Failure | Ownership | Collaboration | Last rehearsed |
|---|---|---|---|---|---|---|---|---|
| 1 | Search latency redesign | p95 latency fix via cursor pagination + index | Dive Deep, Deliver Results | | | Yes | | |

## Rules

- Aim for **6-8 stories total** covering a spread — don't build 6 stories that are all "technical
  challenge I solved solo"; include at least one conflict story, one failure story, and one
  cross-team collaboration story.
- Update "Last rehearsed" every time you say the story out loud (to yourself, in a mock, or in a
  real interview) — stories you haven't said out loud in a month get rusty and start rambling.
- After every mock or real interview, add a row note on which follow-up questions caught you off
  guard, and fix the gap before the next one.
