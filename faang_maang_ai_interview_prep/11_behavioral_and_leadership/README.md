# 11 — Behavioral & Leadership

> **Type:** Study notes + templates (mixed — see each file)

Behavioral rounds are scored as rigorously as coding rounds at most of these companies — Amazon
explicitly grades against Leadership Principles, Google and Meta use structured rubrics. This
folder builds and organizes the story bank you'll draw from, and prepares standard questions
(company-name, salary, "tell me about yourself") that trip up otherwise-strong candidates simply
from lack of rehearsal.

## How to use this folder

1. Read `star_method_guide.md` once.
2. Write 6-8 real stories from your career (see
   [`10_projects_and_resume/star_format_project_stories.md`](../10_projects_and_resume/star_format_project_stories.md)
   for the project-specific angle on the same stories).
3. Map each story into `story_bank_tracker.md` against every question category it can answer —
   most good stories answer 3-4 different question types depending on which part you emphasize.
4. Rehearse out loud, not silently — see
   [`12_mock_interviews/behavioral_mock_interview_template.md`](../12_mock_interviews/behavioral_mock_interview_template.md).
