# Useful GitHub Repos

> **Type:** Study notes

Real, well-known, actually-maintained (or historically significant and still widely referenced)
repositories worth cloning or skimming — not a replacement for the trackers and exercises in this
workspace, but good for cross-checking your own solutions and designs against a second source.

## System design

- **donnemartin/system-design-primer** — the most widely referenced open-source system design
  study repo; its "common patterns" and case-study sections pair well with
  [`06_system_design/fundamentals/`](../06_system_design/fundamentals/).

## DSA / algorithms

- **neetcode-gh/leetcode (NeetCode's companion repo)** — solutions organized by the same
  pattern-based taxonomy used in this workspace; useful for a second worked solution once you've
  attempted a problem from `02_dsa_and_coding/patterns/<topic>/problem_tracker.md` yourself first
  — attempt before you look.

## Python

- **python/cpython** — for genuine "how does this actually work" questions about the language
  (e.g. dict implementation, GC internals) referenced in
  [`03_python_core_and_advanced/14_memory_management_and_gc.md`](../03_python_core_and_advanced/14_memory_management_and_gc.md);
  overkill for interview prep on its own, useful for a specific rabbit hole.

## Backend / Django

- **encode/django-rest-framework** — the DRF source itself is a good reference for the
  patterns discussed in
  [`05_backend_engineering/17_django_and_drf_patterns.md`](../05_backend_engineering/17_django_and_drf_patterns.md),
  since this candidate's background is already DRF-heavy.

## AI / LLM systems

- **langchain-ai/langchain** and **run-llama/llama_index** — even if you don't use these
  frameworks directly, skimming their RAG/retrieval abstractions is a fast way to see common
  architecture patterns referenced in
  [`09_ai_backend_and_llm_systems/02_rag_system_architecture.md`](../09_ai_backend_and_llm_systems/02_rag_system_architecture.md).

## How to use this list

Skim, don't study — these are for cross-referencing a specific design/solution decision you've
already attempted, not for reading start-to-finish.
