# Company Interview Patterns

> **Type:** Study notes

## How to use this folder

**Interview process varies by role, team, level, location, and hiring cycle/year** — nothing here
is a guaranteed loop structure, and every file restates this caveat because it matters more than
any individual detail below it. Treat everything here as "commonly reported pattern," not "the
process."

Per [`00_master_plan/priority_topics.md`](../00_master_plan/priority_topics.md) (Tier 4), this is
**not** ongoing study time. Read the 1-2 files for companies you're actually applying to shortly
before you apply — not weeks in advance, and not all seven files as a study block. Your hours go
into [`02_dsa_and_coding/`](../02_dsa_and_coding/), [`06_system_design/`](../06_system_design/), and
[`11_behavioral_and_leadership/`](../11_behavioral_and_leadership/); this folder just tells you how
to aim that prep at a specific company in the final stretch before an application or a scheduled
loop.

## Shared structure

Each company file covers the same seven sections so you can scan them the same way under time
pressure: interview stages, coding expectations, system design expectations at 3 YOE, behavioral
expectations, common evaluation criteria, how prep should differ, and a company-specific checklist.
